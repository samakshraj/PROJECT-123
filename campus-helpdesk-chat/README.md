# Student Dashboard and API

This folder contains the student dashboard and shared FastAPI service. It is part of the Campus Helpdesk repository; install JavaScript dependencies once from the repository root with `npm install`.

From the repository root, run `npm run dev` to start the dashboard on port 5174 and `npm run dev:full` to start it with the API. The shared launcher uses the Python environment at `campus-helpdesk-chat/.venv`.

See the [API setup guide](rag-service/README.md) for Firebase, SQLite, PDF indexing, and service configuration.
